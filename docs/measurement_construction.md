# 测度构建说明（Measurement Construction）

> 本文件是论文"研究设计"章节的技术底稿：把"如何从年报文本得到一个公司—年度的数字化转型指标"拆成可复现的六个环节，并给出每个环节的**处理规则、参数取值与对应代码位置**。

---

## 1. 概念界定：什么是"企业数字化转型"

本文把**企业数字化转型**界定为：

> 企业为应对数字技术（大数据、云计算、人工智能、区块链、物联网、5G 等）带来的机会与压力，在**技术基础、商业模式、战略意图、组织能力**四个层面主动进行的系统性变革程度。

采用四维分解，避免把"数字化"简化为"是否用电脑"：

| 维度 | 内涵 | 种子词示例 |
|---|---|---|
| **技术应用** | 底层数字技术的引入与部署 | 人工智能、大数据、云计算、区块链、工业互联网、数字孪生 |
| **商业模式** | 面向客户与渠道的模式创新 | 电子商务、平台化、精准营销、用户画像、跨境电商、直播电商 |
| **战略引领** | 战略层面的数字化意图与承诺 | 数字化转型、数字化战略、数字经济、数字生态、数智化 |
| **组织赋能** | 组织、流程与人才的配套变革 | 数字化组织、数字人才、流程再造、敏捷组织、数字化运营 |

**测度取向**：采用**文本披露强度**（disclosure intensity）而非"实际投入水平"。理由是年报 MD&A 是管理层主动叙事，其数字化表述强度同时反映**战略意图**与**实施进展**，是文献中主流做法（吴非等, 2021；袁淳等, 2021）。该取向的代价是可能受"策略性披露"影响，本文通过替代指标收敛效度检验与 IV 回归缓解。

## 3. 文本清洗与分词规则

按顺序执行七条规则（`code/02_clean_and_segment.py`）：

| # | 规则 | 说明 |
|---|---|---|
| 1 | 结构化噪声剔除 | HTML 标签、URL、邮箱、页码页眉（`第X页/共X页`）、多余空白 |
| 2 | 纯数字串剔除 | 正则 `(?<![A-Za-z0-9])\d+(?![A-Za-z0-9])`；**保留含字母的短代号**（5G、AI、O2O），避免误删领域词 |
| 3 | 长英文词剔除 | 长度 ≥ 3 的纯英文单词（保留缩写） |
| 4 | 标点与特殊符号剔除 | 仅保留中文字符、字母与数字 |
| 5 | **分词** | `jieba` 精确模式，并加载 `data/lexicon/segmentation_dict.txt` 领域词典 |
| 6 | 去停用词 | `data/lexicon/stopwords_zh.txt` |
| 7 | 词性过滤 | 仅保留 `n/nr/ns/nt/nz/nl/ng/vn/v/vd/a/an/ag/al/j/l/i/eng`；剔除长度 < 2 的词 |

**关于"分词词典 ≠ 测度词典"**：`segmentation_dict.txt` 只负责保证"数字孪生""工业互联网""线上线下一体化"这类词不被切碎，它**可以包含**种子词典之外的词；而"哪些词算作数字化转型的度量"完全由第 4 步的**测度词典**决定。二者分离，避免了"用答案做分词"的循环论证。

## 4. 构建路径：词典法为主，词向量扩展为辅

### 4.1 路径 A：人工种子词典法（基线）

从文献与政策文本中人工整理 **49 个关键词**，按四维分类，构成 `data/lexicon/seed_lexicon.txt`。

- 优点：可解释、可复现、无监督学习随机性；
- 缺点：**召回率有限**，会漏掉未列入词表但语义同属数字化的表述（如"智能制造""云平台""智慧物流"）。

### 4.2 路径 B：词向量语义扩展（主用）

为解决漏检，在种子词典基础上自动回收领域词：

**Step 1 — 共现矩阵。** 在文档内以窗口 `W = 10` 统计词对共现，按词距做倒数加权 `1/|i−j|`。

**Step 2 — PPMI 加权。**
```
PMI(i,j) = log[ (C(i,j) · ΣC) / (C(i,·) · C(·,j)) ]
PPMI(i,j) = max( PMI(i,j) − log(1), 0 )
```

**Step 3 — 词向量。** 对 PPMI 矩阵做**截断 SVD**（`k = 100`），得到 `W = U_k · √Σ_k`，并按行做 L2 归一化。依据 Levy & Goldberg (2014)，Skip-gram + 负采样（Word2Vec 的 SGNS）的最优解等价于对 PPMI 矩阵的**移位分解**，因此"PPMI + SVD"是一种无需外部大语料、可在小样本年报语料上直接训练的词向量方案。

**Step 4 — 近邻扩展与阈值筛选。** 对每个种子词取语义近邻，候选词须同时满足：

| 条件 | 参数 | 取值 |
|---|---|---|
| 语料频次 | `min_freq_keep` | ≥ 8 |
| 与种子词最大余弦相似度 | `sim_threshold` | ≥ 0.55 |
| 至少与 N 个**不同**种子词相似度 > 0.20 | `n_seed_neighbors` | ≥ 3 |
| 扩展词数量上限 | `topn_expand` | 60 |

候选词按**最近种子词的维度**自动归类，"是否纳入"标记写入 `data/lexicon/expanded_lexicon.csv`，全部候选（含未纳入）保留在 `lexicon_candidates.csv` 供人工复核。

> 代码：`code/03_build_lexicon.py`

## 5. 从文本到"公司—年度"面板的聚合

对第 `i` 家企业第 `t` 年：

**① 词频**
```
Hits_it = Σ_{k ∈ Lex} f_{k,it}
```
`f_{k,it}` 为关键词 `k` 在文本中的词次。

**② 分维度得分**（四维各自求和）`Hits_{d,it}`。

**③ 长度归一（密度）**
```
Density_it = Hits_it / Tokens_it × 1000
```

**④ TF-IDF 加权**
```
TFIDF_it = Σ_k tf_{k,it} × log( N / (1 + df_k) )
```
`N` 为文档总数，`df_k` 为包含词 `k` 的文档数，用于压低"公司""经营"这类高频通用词的影响。

**⑤ 对数化**
```
Dig_it = ln(1 + Hits_it)
```

**⑥ 行业×年度去均值 + 标准化（主指标）**
```
Dig_index_it = ( Dig_it − mean(Dig | 行业 m, 年度 t) ) / sd( · )
```
这一步剔除"所有行业都在讲数字化"的时代共同趋势与行业系统性差异，使系数具有"相对于同行业同年份平均水平的**标准差变动**"这一经济含义。

> 代码：`code/04_compute_index.py`，产物 `data/processed/firm_year_digital_index.csv`

## 6. 测度效度检验（本文的方法论增量）

| 检验 | 做法 | 预期 |
|---|---|---|
| **① 人工编码比对** | 随机抽取 200 个公司—年度，按"是否出现数字化战略表述 / 投入承诺 / 落地案例"三项人工打分（1—5 分），与机器指标计算 Spearman / Pearson 相关 | ρ 显著为正且 > 0.6 |
| **② 替代指标收敛效度** | 与数字技术专利数、研发投入强度、数字类无形资产占比、是否发生数字化并购做 Spearman 相关 | 全部显著为正 |
| **③ 多口径一致性** | 主指标与"仅种子词典""TF-IDF 加权""密度归一""对数词频"四种口径做相关 | ρ > 0.8 |
| **④ 留出词回收率** | 语料中人为放入 **35 个种子词典之外的数字化领域词**（留出词），检验词向量扩展能自动找回多少 | 回收率越高说明词典召回越充分 |

> 代码：`code/05_regression.py::t2_validity`，产出 `results/tables/T2_validity.csv`
