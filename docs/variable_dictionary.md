# 变量字典（Variable Dictionary）

> 本文件对应论文"研究设计"中的**变量定义表**，给出全部变量的名称、符号、定义、测度方式与数据来源。
> 数据来源列中：**CSMAR / CNRDS / 巨潮资讯** 为真实研究应使用的数据源；**本仓库** 表示由 `code/00_generate_demo_data.py` 生成的仿真数据（生成规则见 `docs/data_source_statement.md`）。

## 一、被解释变量

| 变量名称 | 符号 | 定义与测度 | 数据来源 |
|---|---|---|---|
| 全要素生产率 | `tfp_lp` | 采用 **LP 法**（Levinsohn–Petrin, 2003）估计的企业全要素生产率，取自然对数。以主营业务收入为产出、固定资产净额为资本投入、员工人数为劳动投入、购买商品接受劳务支付的现金为中间投入 | 真实研究：CSMAR 财务报表 + 生产函数估计；本仓库：`data/raw/financials.csv` |
| 总资产收益率 | `roa` | 净利润 / 总资产平均余额，替代绩效指标（稳健性检验用） | 同上 |

## 二、核心解释变量（NLP 测度）

| 变量名称 | 符号 | 定义与测度 | 数据来源 |
|---|---|---|---|
| 企业数字化转型程度（主指标） | `dig_index` | 年报 MD&A 文本中数字化关键词词频 `Dig_it = ln(1 + Σ_k f_{k,it})`，再经**行业×年度去均值**并标准化 | 真实研究：巨潮资讯网年报全文（2013—2023）；本仓库：`data/raw/annual_reports.csv` |
| 数字化词频（原始） | `dig_hits` | 扩展测度词典中各关键词在单篇年报中出现的**总词次** | 同上 |
| 对数词频 | `dig_ln` | `ln(1 + dig_hits)` | 同上 |
| 每千词词频密度 | `dig_density` | `dig_hits / n_tokens × 1000`，消除文本长度差异 | 同上 |
| TF-IDF 加权得分 | `dig_tfidf` | `Σ_k tf_k × log(N / df_k)`，降低高频通用词权重 | 同上 |
| 仅种子词典口径 | `dig_seed_index` | 仅使用人工种子词典（不含词向量扩展词）计算的同口径指标 | 同上 |
| 四维度得分 | `dim_{技术应用\|商业模式\|战略引领\|组织赋能}_idx` | 各维度关键词词频对数化后行业年度去均值标准化 | 同上 |
| 是否披露数字化转型 | `digital_disc` | 主指标高于行业年度中位数取 1（倾向得分匹配的分组变量） | 由 `dig_index` 派生 |
| 数字技术专利数 | `digi_patent` / `ln_patent` | 企业当年申请的与数字技术相关的专利数量（取对数） | 真实研究：CNRDS 专利数据库；本仓库：`data/raw/alt_indicators.csv` |
| 研发投入强度 | `rd_ratio` | 研发支出 / 营业收入 | 同上 |
| 数字类无形资产占比 | `intangible_digi` | 数字技术类无形资产 / 总资产 | 同上 |

## 三、机制变量

| 变量名称 | 符号 | 定义与测度 | 数据来源 |
|---|---|---|---|
| 融资约束 | `sa_index` | **SA 指数**：`−0.737×Size + 0.043×Size² − 0.040×Age`；数值越大表示融资约束越强（鞠晓生等, 2013） | 真实研究：CSMAR 计算；本仓库：`financials.csv` |
| 运营效率 | `turnover` | 总资产周转率 = 营业收入 / 总资产平均余额 | 同上 |

## 四、控制变量

| 变量名称 | 符号 | 定义与测度 | 数据来源 |
|---|---|---|---|
| 企业规模 | `size` | 总资产的自然对数 | CSMAR |
| 上市年限 | `age` | 观测年度 − 上市年度 | CSMAR |
| 资产负债率 | `lev` | 总负债 / 总资产 | CSMAR |
| 盈利能力 | `roa` | 净利润 / 总资产平均余额 | CSMAR |
| 成长性 | `growth` | 营业收入增长率 | CSMAR |
| 现金持有 | `cash` | 货币资金 / 总资产 | CSMAR |
| 董事会规模 | `board` | 董事会人数 | CSMAR 治理结构数据库 |
| 独立董事比例 | `indep` | 独立董事人数 / 董事会人数 | CSMAR |
| 两职合一 | `dual` | 董事长兼任总经理取 1，否则取 0 | CSMAR |
| 第一大股东持股 | `top1` | 第一大股东持股比例 | CSMAR |
| 是否四大审计 | `big4` | 由四大会计师事务所审计取 1，否则取 0 | CSMAR |

> 注：在**企业固定效应**模型中，`soe`（产权性质）、`hightech`（行业属性）等不随时间变化的变量被个体效应吸收，故仅用于**分组异质性分析**而不作为控制变量进入基准回归；`age` 与年度固定效应完全共线（`age_it = year_t − ipo_year_i`），因此在固定效应模型中亦不作为控制变量。

## 五、分组与工具变量

| 变量名称 | 符号 | 定义 | 用途 |
|---|---|---|---|
| 产权性质 | `soe` | 实际控制人为国有取 1，否则取 0 | 异质性分组 / 交互项 |
| 高新技术行业 | `hightech` | 属于信息传输、软件和信息技术服务业，或制造业中的计算机通信与其他电子设备制造业取 1 | 异质性分组 / 交互项 |
| 行业 | `industry`, `industry_name` | 证监会 2012 行业分类门类（制造业取二级代码） | 行业年度去均值、聚类 |
| 同群数字化水平 | `iv_peer` | `(行业×年度内 dig_index 之和 − 本企业 dig_index) / (组内企业数 − 1)` | **工具变量**：同行业同年度其他企业的数字化程度均值 |

## 六、文字资料（文本测度输入）

| 名称 | 文件 | 说明 |
|---|---|---|
| 年报 MD&A 语料 | `data/raw/annual_reports.csv` | 字段：`doc_id, stock_code, year, industry, industry_name, title, text` |
| 种子词典 | `data/lexicon/seed_lexicon.txt` | 人工整理的 49 个数字化转型关键词，分四个维度 |
| 分词词典 | `data/lexicon/segmentation_dict.txt` | 仅用于保证术语切分边界，**不等于测度词典** |
| 停用词表 | `data/lexicon/stopwords_zh.txt` | 中文停用词表 |
| 扩展词典 | `data/lexicon/expanded_lexicon.csv` | 种子词 + 词向量自动扩展词，含相似度与是否纳入标记 |
| 留出词真值 | `data/raw/heldout_terms.txt` | 语料中出现但种子词典未收录的领域词，用于计算"留出词回收率" |
| 人工编码样本 | `data/raw/manual_coding_sample.csv` | 200 份年报的人工评分（1—5 分）与分维度评分，用于测度效度检验 |
